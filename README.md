Hair by Somila SN 💗
About the Project
Hair by Somila SN is a hair shopping app I created using Flutter and
Dart.

The idea behind this project is to give customers a simple and beautiful
way to browse different hair products, check prices, and add their
favourite items to a shopping cart.

I chose a pink theme to give the app a soft, stylish look that matches
the beauty and hair industry.
Features
- Home Page: Welcomes customers to Hair by Somila SN.
- Products Page: Displays the available hair products and their
  prices.
- Shopping Cart: Allows customers to add products to their cart.
- Quantity Controls: Customers can increase or decrease the
  quantity of each product.
- Price Calculation: Automatically calculates the total cost of
  the items in the cart.
- Checkout Button: Includes a checkout button for the shopping
  experience.
- Pink Theme: A simple and attractive design using pink and white
  colours.

Getting Started
Follow these steps to run the project on your computer.
Requirements
Make sure you have the following installed:
- Flutter SDK
- Dart SDK (included with Flutter)
- Visual Studio Code
- An emulator or a connected device, or a supported desktop
  environment
Installation
1. Clone the repository:
   git clone https://github.com/Zandile11/hair-by-somila-sn.git
2. Open the project folder:
   cd hair_by_somila_sn
3. Install the project dependencies:
   flutter pub get
4. Run the application:
   flutter run
Make sure you run these commands from the correct project directory.
How the App Works
When customers open the app, they see a welcome page with the Hair by
Somila SN name and a button to start shopping.

They can visit the products page to browse the available hair styles and
view their prices.

When a customer adds a product to the cart, the app updates the cart
quantity and displays a confirmation message.

Customers can then open the cart to view their selected products, change
quantities, and see the total price.

The checkout button currently displays a message because the payment and
ordering process has not yet been implemented.
